# Where the shot was born

The published build of the viewer. Source, tests and documentation live on the `main` branch.

**Open it:** https://sfsilvajacquier.github.io/where-the-shot-was-born/

Man-to-man defence as a system in tension, read backwards from the shot, on
[SkillCorner's basketball open data](https://github.com/SkillCorner/opendata-basketball) — Liga ACB 2025-2026, ten games of
tracking. Every number comes from that data; nothing is read from video.

The JSON under `possessions/`, `reports/`, `rosters/`, `games/` and `players/` is generated by `courtlab` from SkillCorner's
dataset, and the page that names every term marks each figure as SkillCorner's, computed here, or only drawn.

This branch is generated — do not edit it by hand. Rebuild it with `uv run courtlab site` on `main`.

its licence beside it.
